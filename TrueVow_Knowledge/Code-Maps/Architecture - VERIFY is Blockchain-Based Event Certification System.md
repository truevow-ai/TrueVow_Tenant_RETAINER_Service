# VERIFY is Blockchain-Based Event Certification System

VERIFY is NOT document verification. It is a blockchain-based verification system that certifies every event triggered for a law firm on the platform has not been tampered with. INTAKE gets a VERIFY certification that its content was unchanged. SETTLE reports are similarly VERIFY-certified. LEVERAGE application of VERIFY is still to be determined.
