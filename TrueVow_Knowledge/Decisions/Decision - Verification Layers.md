# Verification Layers

AUTHOR VERIFICATION = tests by implementation agent. FRESH-SESSION QA = separate agent session with no implementation context. CTO AUDIT = architectural evidence review. For G13 require fresh-session QA + CTO audit after production integrations exist. Same model writing code and acceptance tests is NOT independent verification.
